# Виявлення дорожніх знаків класичними методами обробки зображень

Програма знаходить дорожній знак на фотографіях із датасету GTSRB за допомогою
двох пайплайнів класичних методів обробки зображень. Стадії кожного пайплайна
виконуються автоматично одна за одною, результат кожної стадії зберігається
як окреме зображення, а метрики якості - у CSV і JSON.

## Пайплайн 1: пошук круглого знака за кольором і формою

| № | Стадія (категорія) | Методи | Вхід → вихід | Файл результату |
|---|---|---|---|---|
| 1 | Колірна корекція | перетворення RGB → HSV, нормування яскравості, порогова червона маска | кольорове фото → бінарна маска червоних пікселів | `1_red_mask.png` |
| 2 | Морфологічна обробка | закриття, відкриття, заповнення дірок, внутрішня межа | маска → суцільна область знака та її контур | `2_morphology.png`, `2_edges.png` |
| 3 | Перетворення Хафа | детекція кіл голосуванням в акумуляторі | контур → центр і радіус кола, рамка знака | `3_hough.png` |

## Пайплайн 2: виділення знака як області

| № | Стадія (категорія) | Методи | Вхід → вихід | Файл результату |
|---|---|---|---|---|
| 1 | Гістограмна корекція | гістограмне вирівнювання яскравості | фото → контрастне фото | `1_equalized.png` |
| 2 | Фільтрація | білатеральний фільтр | фото → фото без шуму зі збереженими межами | `2_bilateral.png` |
| 3 | Сегментація | регіональне зростання фону від країв кадру з адаптивним порогом | фото → маска знака, рамка знака | `3_region.png` |
| 4 | Геометричні перетворення | афінне нормування з білінійною інтерполяцією | фото і рамка → знак 48×48 | `4_normalized.png` |

## Структура проєкту

| Файл / папка | Вміст |
|---|---|
| `traffic_signs_stem.py` | головна програма: завантаження зображень, запуск пайплайна, збереження стадій і метрик |
| `pipelines.py` | пайплайни 1 і 2 |
| `methods/color.py` | RGB → HSV, нормування яскравості, червона маска |
| `methods/morphology.py` | ерозія, дилатація, відкриття, закриття, заповнення дірок, контур |
| `methods/hough.py` | перетворення Хафа для кіл |
| `methods/histogram.py` | гістограмне вирівнювання |
| `methods/bilateral.py` | білатеральний фільтр |
| `methods/region_growing.py` | регіональне зростання |
| `methods/geometry.py` | афінне перетворення, білінійна інтерполяція |
| `methods/metrics.py` | IoU, MSE, PSNR, SSIM |
| `experiments.py` | експерименти: шум, якість фільтра, освітлення; таблиці й графіки |
| `config.json` | параметри всіх методів |
| `tests/` | автотести (pytest) |
| `tools/select_dataset.py` | відбір 100 зображень із GTSRB |
| `data/images/`, `data/annotations.csv` | вибірка і розмітка (група знака, правильна рамка) |

## Встановлення

Потрібен Python 3.9 або новіший.

```
pip install numpy pillow matplotlib pytest
```

## Запуск

Команди виконуються з папки, де лежить `traffic_signs_stem.py`.

**Пайплайн на всій вибірці:**

```
python traffic_signs_stem.py --pipeline 1
python traffic_signs_stem.py --pipeline 2
```

| Аргумент | За замовчуванням | Що задає |
|---|---|---|
| `--pipeline` | `1` | номер пайплайна (1 або 2) |
| `--input` | `data/images` | одне зображення або папка |
| `--annotations` | `data/annotations.csv` | розмітка для обчислення IoU |
| `--config` | `config.json` | файл параметрів |
| `--output` | `results` | папка результатів |

Результати: `results/pipeline1/` або `results/pipeline2/` - папка з картинками
стадій для кожного зображення, `metrics.csv` і `metrics.json`. Підсумок за
групами знаків виводиться в термінал.

**Експерименти** (шум sigma = 0, 10, 25 з seed = 42; якість фільтра; освітлення):

```
python experiments.py
```

Результати: таблиці й графіки в `results/experiments/`.

**Тести:**

```
python -m pytest
```

**Параметри** методів змінюються в `config.json` без зміни коду.
